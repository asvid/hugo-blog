# Devlog — 2026-11-16

## TL;DR

No release this week — this was the week I paid for last week's audit. Dozens of fixes to sync, auth, the watch apps and the design system, plus a CI that now catches the kind of deploy bug that 500'd every task update. Boring on the surface, and that's the point.

## User-facing features

- **Change and reset password actually work on mobile.** Both were hitting routes that didn't exist. A wrong current password no longer burns your session either.
- **Apple Watch got a proper pass.** Pick an energy level for adaptive starts, the idle face shows your real work length instead of 00:00, the Digital Crown adjusts length with a click per step, and a fresh or relaunched watch app no longer shows an empty task list.
- **Timer sync between devices is less haunted.** Stopping a timer on a device that didn't start it records the right session start. Wear OS no longer lets old phone echoes revive a timer you just paused or stopped. Phone + backend + web.
- **Stay signed in after a reinstall.** iOS changing its device id on reinstall used to log you out of a perfectly good session. Now the session follows you.
- **Web: fewer random sign-outs.** A database blip or deploy window no longer kicks every open tab to the login page.
- **Web: Ctrl+Cmd+Enter saves once, not twice** (two sessions on the timeline — oops). Ctrl+Enter also works on Firefox/Zen on macOS, and Mac users see ⌘↵.
- **Web: manual sessions can have no mode.** The form no longer forces Pomodoro.
- **Streaks and calendars survive weird timezones** where DST swallows midnight (Havana, Santiago). Niche, but someone lives there.
- **Accessibility and polish.** Bigger touch targets, proper screen-reader roles, text that grows with font scale instead of clipping, consistent fonts in sheets and the register screen. Wear ambient mode shifts pixels to avoid burn-in.

## Technical improvements

- **Mobile sync is delta-only now.** The old full pull/batch path is gone on mobile and frozen on the backend. One incremental sync per launch instead of two plus a full pull, and it pages properly when there's more to fetch. Phone + backend.
- **Sync can't undo your deletes anymore.** Applying server data is transactional and respects local deletes; a failure rolls back instead of leaving half a page applied. Only changed rows get pushed. Bad rows get quarantined instead of retried forever.
- **Sessions finish once.** If two devices finish the same session, first one wins and side effects don't run twice. Phone + backend.
- **Android tokens moved to a Keystore-encrypted store.** The old encrypted prefs are deprecated; migration only deletes the old copy after the new one reads back correctly. Also excluded from cloud backup.
- **Error handling grew up.** Network failures map to proper typed errors, so retries know what's worth retrying and timeouts stop pretending to be storage errors.
- **Secrets scrubbed from crash reports on iOS** too, not just Android.
- **Less battery and jank.** Lazy screens and tabs, lifecycle-aware updates, websocket only while the app is foreground with network, dropped a 15-minute poller, baseline profile generated on every release for faster cold start.
- **Deploys are safer.** CI now runs the _previous_ release against the _new_ schema before deploying — exactly the bug that shipped green last week. Plus an 80% coverage gate on backend PRs and sharded e2e.
- **Backend ops hardening.** Clean shutdowns for the outbox worker and websockets, timeouts on push and email sends, better health reporting, Grafana alert and a global cap on demo accounts.
- **Web app rework under the hood.** Tailwind retired for design-system tokens, shared modal on native dialogs, accessible icons and colour swatches.
- **Architecture cleanup.** Android and iOS share one navigation shell, module boundaries tightened, shared design-system rows and type roles, repo layouts and docs cleaned up on both sides. [VERIFY — internal only, keep or cut?]
