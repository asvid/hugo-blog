## TL;DR

Last week was paying off the audit. This week I got to build something fun again: the timer can now show time three ways, including an hourglass that drains square by square — on phone, watch, web, notification, complications and Live Activity. Plus 1.18.0 and 1.18.1 went out, and timers finally agree on how long they are.

## User-facing features

- **Timer display: Classic, Minutes, Hourglass.** Pick how the timer looks in Timer settings. Minutes shows just "18" with the ring — less clock-watching. Hourglass swaps numbers for a 5×5 grid that drops a square as time passes. Per device, not synced, because your watch and your laptop don't need the same vibe. Android, iOS, web.
- **…and it follows you everywhere.** Android notification, Wear OS and Apple Watch complications (new Hourglass one on both), Apple Watch app, iPhone Live Activity. The web follows the mode in the tab title, header bar and dashboard tile too.
- **One timer, one length.** An Adaptive timer used to show three different durations on three devices, because each one guessed from its own settings. Now the phase length travels with the timer state and followers just use it. Phone + watch + backend + web.
- **Countdown rings drain instead of fill.** Pomodoro and breaks start full and empty out, like the Apple Watch ring already did. Flow still fills up, because it counts up.
- **Apple Watch timer sync fixed.** A timer started while the watch app was in the background never showed up — every update got rejected as "too old". Oops.
- **Apple Watch tasks look like phone tasks.** Priority stripe, energy dots, toad flag, due date, and the same ordering as the phone's task picker. Before that the watch got... a title.
- **Task sheet redo.** Opens full screen, can't be dragged around, Save sits in the header Todoist-style, and the tools row moved away from the bottom edge where an iOS swipe switched apps instead. More room to type above the keyboard.
- **Wear OS Adaptive starts keep your energy pick** instead of quietly falling back to Medium on the phone.
- **Web: rename goal lines in place.** Click, type, Enter. Mobile could already do this.
- **Web: Log day panel cleanup.** Add session / entry / decision and all the filters moved next to the day they apply to, instead of floating at the top of the page pretending to be filters.
- **Web: log sessions against recently archived tasks.** Recurring tasks never reach "done", so archiving one hid it from the picker. Now archived-in-the-last-week tasks stay listed, struck through.
- **Smaller fixes.** Activity label under the timer is gone (it pushed the whole layout up and the chip already says it). The Log no longer randomly drops your newest decisions until the next change. Live Activity shows the app icon instead of a grey box.

## Technical improvements

- **Timer state carries its planned length.** Older app versions that don't send it can't wipe it, so the rollout doesn't need everyone to update at once. Phone + backend.
- **Display mode reaches the watches over the existing phone ↔ watch channels**, with Classic as the safe default until a value arrives. Complications and notification only refresh when the shown number or square actually changes — fewer wakeups.
- **Log race condition fixed.** Parallel day loads could finish out of order and overwrite newer data with older. Serialized. Caught by the pre-release screenshot tour, twice in a row — that tour keeps paying for itself.
- **Store listings updated** for Decision log, three toads and task search. [VERIFY — all three already live?]
